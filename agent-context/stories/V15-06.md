# V15-06 — Grove bi-color status LED and duty-cycled soil ADC

- **Status:** Blocked on remaining hardware validation
- **Priority:** P1
- **Depends on:** V15-02, V15-04 and V15-05 software contracts
- **Objective:** Add an unambiguous local health LED and acquire a raw YL-38 analog response while
  keeping the corrosion-prone probe powered for a tightly bounded fraction of time.

## Scope

- Drive a two-channel LED through separate ~330 Ω resistors: red=`D6`/GPIO12 and
  green=`D0`/GPIO16. Default wiring is common-cathode; a build flag can invert both channels for a
  common-anode LED and startup must state the selected polarity.
- Map red to sensor/acquisition fault, amber to valid core sensors with MQTT offline or
  unconfigured, and green to valid core sensors with MQTT connected.
- Switch YL-38 VCC with the confirmed high-side 2N3906 PNP: emitter=`3V3`, collector=YL VCC,
  base=`D1`/GPIO5 through 2.2 kΩ, and external 100 kΩ base-to-emitter pull-up. The control is active
  LOW; the GPIO drives only the base and never powers the YL-38 directly.
- Read YL AO on A0 through 47 kΩ top / 15 kΩ bottom, with installed 100 nF (`104`) A0-to-GND.
  YL DO is unused and grounds are common.
- Every 30 seconds, power on, settle for 100 ms, collect a small bounded sample set cooperatively,
  average it, and power off immediately. Publish/display only raw ADC counts.
- Add optional `soil_adc_raw` Grove MQTT state and retained Home Assistant discovery.

## Out of scope

- Moisture percentage, calibration, watering automation, YL DO, direct GPIO sensor power,
  MAX4466, WS2812 support, changing AtmosMesh v1 pins/runtime, or proving the NodeMCU A0 divider.

## Acceptance criteria

- [x] Native tests prove fail-safe active-low OFF initialization, 30 s cadence, 100 ms settle,
  bounded sample count/spacing, average (including numeric zero), immediate OFF on completion/fail,
  hard maximum-on timeout and `millis()` wraparound behavior.
- [x] Normal sampling is cooperative and MQTT reconnect/socket work cannot begin while YL power is
  active. Calculated normal and timeout duty-cycle bounds are documented.
- [x] Before the first completed sample, soil is unavailable/omitted rather than numeric zero.
- [x] Native tests prove red/amber/green logical mapping for common-cathode and common-anode wiring.
  Light/soil missing or uncalibrated values are not faults; explicit acquisition timeout/failure is.
- [x] Profile, serial and wiring docs name D6 red, D0 green, D1 active-low 2N3906 base control, A0
  divider, separate LED resistors, 2.2 kΩ base resistor, 100 kΩ base-emitter pull-up, `104`, DO
  unused and common ground.
- [x] OLED/serial/MQTT show `soil_adc_raw` as a raw diagnostic only; HA discovery has no moisture
  device class, percent unit or calibration claim.
- [x] Existing AtmosMesh v1 behavior/pins and Grove light/environment contracts remain green.
- [x] Fresh independent review precedes flash; reviewed serial evidence proves two scheduled raw
  soil samples and reports software power-off after each sample set.
- [ ] Hardware evidence still covers LED polarity/status colors, switched-rail voltage/current,
  MQTT/HA receipt and physical power-off behavior.

## Validation plan

Add failing host tests for soil timing/actions, ADC semantics, wraparound, LED polarity/status,
profile pins, OLED text, Grove JSON/discovery and state replay. Implement pure policies first, then
compose only thin ESP8266 GPIO/ADC operations. Run native tests, both canonical builds, all
compatibility builds, repository checks and the secret audit. Do not flash in this lane.

## Evidence

- Operator-authorized wiring/cadence contract recorded 2026-08-24. Although the requested maximum
  was 2 Hz, 30 seconds is selected because soil response changes slowly and lower probe duty reduces
  corrosion exposure.
- The operator subsequently confirmed and physically wired the alternative 2N3906 PNP circuit:
  emitter=3V3, collector=YL-38 VCC, base through 2.2 kΩ to D1/GPIO5, 100 kΩ base-emitter pull-up,
  AO through 47 kΩ / 15 kΩ to A0, `104` decoupling and DO unused.
- Operator corrected the live pin contract before production code: installed LED is red D6/GPIO12
  plus green D0/GPIO16; soil power control is D1/GPIO5. D0 is not used for soil power.
- **Red, 2026-08-24:** native compilation failed on missing soil sampler/status LED headers, Grove
  profile fields and `soil_adc_raw` contract. A focused follow-up red failed on the absent shared
  policy that forbids network work while soil power or RC acquisition is active.
- **Green, 2026-08-24:** 91 native tests cover active-low fail-safe OFF, 30 s wrap-safe cadence,
  100 ms settle, five samples at 5 ms spacing, average including valid zero, invalid ADC fail-off,
  250 ms timeout, duty bounds, LED health/polarity, compact OLED text, optional MQTT JSON/discovery
  and pending-state replay. Default and common-anode Grove builds compile.
- **Full gates, 2026-08-24:** `task test` passed 91/91; `task build-all`, `task build`,
  `task build-grove`, direct compatibility builds for `esp32dev` and `esp8266-grove`, and the
  common-anode Grove build all passed. Canonical v1 used 14.6% RAM / 72.8% flash; canonical Grove
  used 42.2% RAM / 29.3% flash. `task check`, `git diff --check` and the generated-secrets
  ignore/untracked audit passed.
- Software acceptance was complete before review. The implementation agent ran no flash command.
- **2N3906 reconciliation, 2026-08-24:** a native compile first failed because the test required
  `soil_power_control_gpio` while production still exposed an obsolete switch-field name. After
  renaming the profile/runtime metadata and diagnostics to transistor control/base terminology, all
  91 native tests passed.
- The post-wiring full matrix passed: `task build-all`, `task build`, `task build-grove`, direct
  `esp32dev` and `esp8266-grove` compatibility builds, the common-anode Grove build, `task check`
  and `git diff --check`. Canonical v1 remains 14.6% RAM / 72.8% flash; Grove is 42.2% RAM / 29.3%
  flash. No flash command was run by the implementation agent.
- **Reviewed hardware pass, 2026-08-24:** after independent approval of head `c880afe`, the
  coordinator ran `ESP_PORT=/dev/cu.usbserial-0001 task flash-v1-5`. Esptool identified the
  ESP8266EX, 26 MHz crystal and MAC `2c:3a:e8:43:7c:16`, wrote 310,288 bytes, verified the hash and
  hard-reset the board. More than 60 seconds of 115200-baud serial showed two cycles about 30
  seconds apart; both reported exactly `soil: ok adc_raw=214 samples=5 power=off`. DHT11 was stable
  at 25.0 °C / 36–37% RH, BMP180 at 24.4–24.5 °C / 982.6–982.8 hPa, light at 389–452 µs, and core
  sensor health was okay.
- The serial `power=off` text proves the firmware completed its OFF action; it does not prove the
  switched-rail voltage or physical current. LED colors/polarity, probe calibration, MQTT broker/HA
  receipt and OLED pixels remain unconfirmed.
