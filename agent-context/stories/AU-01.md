# AU-01 — Display and touch bring-up, geometry locked from evidence

- **Status:** Done (bench-verified 2026-09-20)
- **Priority:** P0
- **Milestone:** Aura v1
- **Depends on:** nothing

## User story

As the builder, I want the CYD's panel driven at its true geometry in portrait, so that every
later screen is laid out against a surface that is known-correct rather than one that silently
clips a quarter of itself.

## Outcome

`ili9xxx` with `model: ILI9341`, `dimensions: 240x320`, `transform: swap_xy: true`, LVGL left at
`rotation: 0`. MADCTL `0x28`. No software rotation anywhere.

## What the bench established, and what it cost

Five wrong explanations were flashed and withdrawn before the right one. Recorded so the next
person does not repeat them:

| Config | Result | Verdict |
| --- | --- | --- |
| MADCTL `0x48`, 240x320 | horizontal, 25 % missing | native addressing is not portrait here |
| MADCTL `0x08`, 240x320 | mirrored, 25 % missing | mirror flips which edge is blank |
| MADCTL `0x68`, 320x240 | looked like full coverage | **suspected wrapped write, not coverage** |
| `0x68` + LVGL `rotation: 90` | mirrored, stretched | ESPHome LVGL software rotation stretches here |
| MADCTL `0x08`, 320x240, no LVGL | **full coverage** | the panel is landscape-native at MV=0 |

Two conclusions worth keeping. **LVGL's `rotation:` must not be used with `ili9xxx`** — the
component never registers hardware rotation, so LVGL always rotates in software, and the flush
path stretches the result. Orientation comes from `transform:` only. And **`buffer_size` is not a
geometry knob** — raising it 25 % → 50 % changed nothing, which is what ruled out the
flush-chunk theory.

## Acceptance criteria

1. Boot log shows `Wrote MADCTL 0x28` and `Dimensions: 240px x 320px`.
2. A full-screen test pattern reaches all four edges with no blank band.
3. A diagonal drawn corner to corner is one unbroken straight line — the wrap detector.
4. `docs/hardware/inventory.md` records the final config and the withdrawn theories.

## Evidence

`firmware/spike/geometry-probe.yaml`, boot logs of 2026-09-20.
