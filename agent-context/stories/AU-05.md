# AU-05 — Wi-Fi provisioning from the touchscreen, no cable

- **Status:** Ready
- **Priority:** P0
- **Milestone:** Aura v1
- **Depends on:** AU-01, AU-04

## User story

As the recipient, I want to put the thing on a shelf, tap my network and type my password, so
that it works without anyone flashing it for me.

This is giftability requirement **G1**. If it fails, the product fails.

## Outcome

ESPHome's `WiFiComponent` exposes what this needs at runtime — verified in the component source
before committing to the approach:

| Need | API |
| --- | --- |
| list networks | `start_scanning()`, `get_scan_result()`, `keep_scan_results: true` |
| join and persist | `save_wifi_sta(ssid, password)` — writes NVS and reconnects |
| forget | `save_wifi_sta("", "")` then restart |

Flow: **scan → pick → type → test → save**. Credentials are never saved before a join succeeds,
so a typo cannot brick the device into a network it can never reach.

## Screens

1. **Network list** — SSID, signal bars, lock glyph. Sorted by RSSI. A refresh button.
2. **Password** — LVGL `keyboard` + `textarea`, password mode with a reveal toggle.
3. **Joining** — spinner with the SSID, and a cancel that returns to the list.
4. **Result** — success returns to Now; failure names the reason and returns to the password
   field with the text preserved.

## The resistive-touch problem, stated honestly

This panel is resistive and the keyboard keys are small. Typing a 20-character WPA2 password on
it is the single worst moment in the product. Mitigations, in order:

- Keys sized to the panel, not to the font — minimum 30 px touch targets on a 240 px width.
- A reveal toggle, so a mistyped character is visible rather than inferred from a failure.
- Text preserved across a failed attempt.
- **A fallback that needs no typing at all:** if the device cannot join, it raises its own AP and
  `captive_portal` serves the same form to a phone, which has a real keyboard.

The fallback is not an admission of defeat; it is the path most recipients will actually take.

## Acceptance criteria

1. A factory-reset unit joins a network with no serial cable and no flashing.
2. A wrong password produces a named failure, not a hang, and the text survives.
3. Credentials persist across a power cut.
4. "Forget network" returns the unit to the setup AP.
5. While unprovisioned, the Now screen still shows sensor readings — G4 is not suspended
   during setup.
