# V15-02 — Shared multi-variant firmware architecture

- **Status:** Done
- **Priority:** P0
- **Depends on:** V15-01
- **Objective:** Build ESP32 v1 and ESP8266 Grove v1.5 from one PlatformIO project without cloning
  the complete ESP32 application.

## Scope

- Add a 4 MB NodeMCU-style ESP8266 PlatformIO environment.
- Add a thin Grove entrypoint/profile and shared pure formatting/domain behavior while preserving
  the existing ESP32 entrypoint.
- Preserve the existing `esp32dev` image and commands.
- Add explicit Grove build/flash/monitor tasks while retaining the flash authorization boundary.

## Out of scope

- Physical upload, MQTT/Wi-Fi, sensor calibration, or refactoring unrelated ESP32 subsystems.

## Acceptance criteria

- [x] Native tests prove Grove identity, pins, health formatting and missing-value behavior.
- [x] Source filters select the existing ESP32 entrypoint for `esp32dev` and the thin Grove
  entrypoint plus its shared formatter for `esp8266-grove`.
- [x] `task test`, `task build`, `task build-grove`, `task check` and `git diff --check` pass.
- [x] No secrets or generated binaries are tracked.

## Validation plan

Add failing native tests before the shared Grove production utilities, capture the expected red
failure, implement the smallest profile/formatter, then run the full gate matrix.
