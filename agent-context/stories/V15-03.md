# V15-03 — Grove OLED, BMP180 and DHT11 bring-up

- **Status:** Blocked
- **Priority:** P0
- **Depends on:** V15-02, fresh independent review and coordinator hardware run
- **Objective:** Sample the fitted sensors, show trustworthy values/health on the 128×32 OLED and
  emit actionable serial diagnostics.

## Scope

- Explicit `Wire.begin(GPIO4, GPIO0)` shared bus setup.
- SSD1306 128×32 at 0x3C/0x3D, BMP180 at 0x77 and DHT11 on profile GPIO14.
- Distinguish unavailable/failed readings from a valid numeric zero.

## Out of scope

- Soil, light, sound, Wi-Fi/MQTT and flashing from this implementation lane.

## Acceptance criteria

- [x] Firmware compiles for the detected ESP8266 flash geometry.
- [x] Native tests cover present, partial and all-missing OLED/serial health states.
- [x] Serial startup reports product ID, exact pins, GPIO0 warning and per-device init result.
- [ ] A physical run proves the OLED and both sensors or records each failure explicitly.

## Validation plan

First validate pure formatting natively and compile the image. Authorization to replace AT firmware
is recorded. After fresh independent review, the coordinator will flash once, capture boot
diagnostics and compare readings with plausible indoor ranges. Test one disconnected sensor at a
time.

## Evidence

- 2026-08-24 `task build-grove`: success for NodeMCU v2, ESP8266 80 MHz, 4 MB flash; no upload.
- Native formatter tests prove valid zero is displayed as zero while invalid sensor state is
  displayed as dashes/`ERR`.
- `src/products/atmosmesh_grove_v1_5.cpp` explicitly uses `Wire.begin(4, 0)`, initializes OLED
  candidates 0x3C/0x3D and BMP180 0x77, and logs identity, wiring, GPIO0 boot warning and health.
- Every sample probes BMP180 address 0x77. Address loss invalidates prior readings before render;
  address recovery reinitializes the sensor and restores the explicit D2/D3 bus before reading.
- Operator authorized flash on 2026-08-24. Physical criterion remains pending fresh independent
  review and a coordinator-run upload/monitor session; no upload occurred in this implementation.
