# V15-09 — Grove calibrated soil-status LED

- **Status:** Blocked on independent review and controlled soil calibration evidence
- **Priority:** P1
- **Depends on:** V15-06 raw soil acquisition and confirmed installed LED polarity
- **Objective:** Make the canonical installed LED polarity reliable and derive local red/amber/green
  status from system health plus explicitly validated, direction-aware soil calibration.

## Scope

- Make the installed D6 red / D0 green common-anode wiring the canonical Grove profile default.
- Retain an explicit, tested common-cathode build override for alternative hardware.
- Add compile-time soil calibration metadata: enabled state, raw direction, dry cutoff and
  acceptable cutoff. Support both higher-is-wetter and lower-is-wetter directions.
- Validate ADC bounds and direction-consistent strict threshold ordering. Disabled, unknown,
  out-of-range, equal or direction-reversed thresholds are uncalibrated/invalid and fail safe to
  amber, never to a guessed moisture state.
- Apply this exact LED priority:
  1. core sensor or acquisition error → red;
  2. MQTT configured but offline → red; intentionally unconfigured MQTT is neutral;
  3. calibrated soil dry → red;
  4. soil missing, uncalibrated/invalid or calibrated warning band → amber;
  5. calibrated acceptable soil with otherwise healthy system → green.
- Emit non-secret serial diagnostics with final `soil-led-status`, reason, raw state, direction and
  threshold/calibration validation state.

## Out of scope

- Inventing thresholds before operator dry/wet measurements, moisture percentage, MQTT schema or
  Home Assistant device-class changes, watering automation, OLED row changes, sampling cadence,
  switched-power changes, AtmosMesh v1 behavior, or flashing hardware.

## Acceptance criteria

- [x] Canonical Grove and visual-diagnostic images compile common-anode by default; a dedicated
  common-cathode verification image compiles and is host-tested.
- [x] Native tests cover disabled, valid-both-directions, unknown direction, out-of-range, equal and
  direction-inconsistent threshold validation.
- [x] Raw zero remains a valid soil sample; missing/unclassified is never silently converted to a
  calibrated classification.
- [x] Native tests prove the complete LED priority including MQTT configured/offline versus
  intentionally unconfigured and soil missing/acquisition failure/dry/warning/acceptable states.
- [x] Serial diagnostics expose calibration state/direction/cutoffs and final LED reason without
  credentials or moisture/percentage claims.
- [x] Raw `soil_adc_raw` MQTT/discovery semantics, OLED rows, 30-second cadence/power-off,
  diagnostic mode and AtmosMesh v1 remain unchanged.
- [x] Full native/build/compatibility/polarity/diagnostic/check/secret gates pass before commit; no
  flash, self-review or merge occurs.

## Validation plan

Add failing native tests for canonical polarity, calibration validation/classification, final LED
priority and diagnostics before production behavior. Compose the pure policy into the thin Grove
runtime, then compile canonical and common-cathode normal/visual images plus all existing product
and compatibility gates. Do not set real calibration thresholds or flash in this lane.
