# AU-04 — The Now screen: a portrait UI worth putting on a shelf

- **Status:** Ready
- **Priority:** P0
- **Milestone:** Aura v1
- **Depends on:** AU-01, AU-03

## User story

As the recipient, I want one glanceable screen that tells me whether the air is good and what the
room feels like, so that the device earns its place without me learning anything.

## Outcome

A 240×320 portrait screen, dark by default, one idea per zone:

```text
┌────────────────────────────┐
│  BERLIN            09:41   │  status strip: place, clock, wifi dot
├────────────────────────────┤
│                            │
│         ╭────────╮         │  VOC arc, 0–250 mapped to 270°
│        │   104    │        │  the number is the hero
│         ╰────────╯         │
│           FINE             │  the band word, colour-coded
│                            │
├──────────┬─────────────────┤
│  24.5°   │   61%           │  two big tiles
├──────────┴─────────────────┤
│  986 hPa  ·  NOx 1         │  quiet secondary row
├────────────────────────────┤
│   12°  Light rain          │  outdoor strip, only when online
└────────────────────────────┘
```

## Design rules, so it looks designed rather than assembled

- **One accent colour at a time**, taken from the current air band. The arc, the band word and the
  status dot share it; nothing else is coloured.
- **Type scale, not type soup:** montserrat 48 for the VOC number, 28 for tile values, 16 for
  labels, 14 for the secondary row. Four sizes, no more.
- **Labels are lowercase and dim**; values are bright. The eye lands on numbers first.
- **No gridlines, no borders, no gradients.** Separation comes from spacing and a single hairline.
- **Nothing blinks.** A gift on a shelf must be ignorable.

## Colours

| Band | Accent |
| --- | --- |
| Fresh | `#4ADE80` |
| Fine | `#38BDF8` |
| Stuffy | `#FBBF24` |
| Open a window | `#F87171` |
| Unknown / FAULT | `#64748B` |

Background `#0B1220`, surface `#151E2E`, primary text `#E9EEF7`, dim text `#8899AE`.

## Acceptance criteria

1. Renders correctly with no network and no MQTT — G4.
2. Every reading state from AU-03 is visually distinguishable without reading the words.
3. Outdoor strip is absent, not empty, when offline.
4. Text has no clipping or overlap at any value width (`-9.9°`, `1013 hPa`, `500`).
5. Backlight is legible at arm's length in daylight and not glaring at night.
