# V15-04 — Grove soil, light and sound follow-on

- **Status:** Planned
- **Priority:** P2
- **Depends on:** V15-03 and an approved ADC/power design
- **Objective:** Evaluate useful plant/light/noise trends without overstating uncalibrated sensors.

## Candidate scope

- YL-69 probe with YL-38 interface and switched power to limit corrosion.
- LDR relative brightness.
- MAX4466 relative sound activity.
- Select an external ADC/multiplexer or justified threshold/RC method for the single-ADC ESP8266.

## Out of scope

- Calibrated lux or decibels, speech capture, automatic watering, life-safety claims.

## Acceptance criteria

- [ ] Exact board ADC input range and each module's output range are measured before connection.
- [ ] Analog outputs are never tied together and cannot exceed the GPIO/ADC limit.
- [ ] YL-69 is powered only for bounded measurements.
- [ ] UI and diagnostics call uncalibrated results `relative`/`raw`, not lux or dB.
- [ ] Failure/disconnection behavior and corrosion/power lifecycle are tested.

## Validation plan

Photograph and identify modules, measure rails and maximum outputs, approve the interface design,
then add one sensor per red/green test and bench-validation cycle.
