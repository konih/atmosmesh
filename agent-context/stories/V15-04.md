# V15-04 — Grove uncalibrated RC light response

- **Status:** Blocked on reviewed hardware validation
- **Priority:** P1
- **Depends on:** V15-02 and installed D7 RC wiring contract
- **Objective:** Measure a bounded raw LDR charge time without consuming A0 or claiming calibrated
  illuminance.

## Scope

- Installed circuit: `3V3 → LDR → 1 kΩ → D7/GPIO13 measurement node`; 100 nF from node to GND.
- Discharge D7 low, release it as an input, and measure time-to-high with a hard timeout.
- Model the measurement lifecycle as a host-tested, cooperative state machine.
- Report valid response time as `light_charge_us`; lower values mean brighter conditions.
- Show raw microseconds or explicit missing state on serial and the 128×32 OLED.

## Out of scope

- Lux, percent brightness, calibration, A0, YL-69/YL-38, MAX4466, automatic lighting/watering,
  or accuracy claims.

## Acceptance criteria

- [x] Native tests cover discharge, release, valid time-to-high, immediate/saturated input and hard
  timeout/disconnection.
- [x] The runtime advances the measurement in short loop ticks and never busy-waits for the RC edge.
- [x] Valid values have explicit microsecond units and document that lower means brighter.
- [x] Timeout/saturation/missing state is unavailable, never numeric zero, lux or percent.
- [x] D7/GPIO13 is the only new pin; A0 remains free and AtmosMesh v1 pins/runtime are unchanged.
- [x] Serial and OLED both distinguish valid raw response time from missing state.
- [ ] Reviewed hardware evidence shows bounded raw timing and response to changed light conditions.

## Validation plan

Start with native state/policy and formatter failures, implement the pure policy, then compose the
ESP8266 pin actions. Run native tests and both product builds. Physical timing/brightness response
remains pending until a reviewed image is flashed by the coordinator.

## Evidence

- Operator confirmed the installed bare-LDR RC wiring on 2026-08-24. No physical firmware evidence
  exists yet; this lane must not flash.
- MAX4466 was explicitly dropped. A0 is reserved for a later, separately designed YL-38 story.
- **Red, 2026-08-24:** native compilation failed because `atmosmesh/rc_light.hpp` and the new Grove
  light/profile/display fields did not exist.
- **Green, 2026-08-24:** cooperative policy tests cover 1 ms discharge, release-to-input, valid
  127 µs completion, immediate saturation and 200 ms timeout/disconnection. A focused red/green
  edge test proves HIGH first observed after the deadline remains a timeout. OLED tests cover raw
  microseconds and `L -----us`; serial explicitly says raw/lower-is-brighter or unavailable cause.
- The Grove composition root maps only policy-requested pin actions to D7/GPIO13 and calls the policy
  from the normal loop with `yield()`. There is no RC busy-wait.
- **Software gates, 2026-08-24:** `task test` passed all 85 tests. Canonical and compatibility Grove
  builds passed at 41.0% RAM / 29.0% flash. `task build-all`, v1/ESP32 builds, `task check` and
  `git diff --check` passed. No flash command was run.
